# Nexus Digital: proposal concept

Sales page and motion graphics concept for a fictional AI agents agency, in Portuguese.

Live at https://sataker.github.io/nexus-digital-proposal/

- `index.html`: sales page
- `NexusProposal.tsx`: Remotion composition for the vertical video
- `motion_concept.md`: visual concept and scene plan

No build step: GitHub Pages serves these files directly from `main`. To preview locally, run `python3 -m http.server` and open http://localhost:8000.
